# SALIE AI - The Ultimate University Student Assistant

SALIE AI is an intelligent Android application designed to streamline the university experience by integrating three essential pillars of student life: **Study**, **Style**, and **Life**. Built with Java and modern Android components, it provides a unified dashboard for managing academic goals, personal fashion, and daily wellness.

---

## 🚀 Key Features

### 📚 Study Mode
Empower your academic journey with tools designed for efficiency:
- **AI Tutor & Notes**: Integrated AI assistance for explaining complex topics and organizing study materials.
- **Interactive Learning**: Quizzes and flashcards to reinforce knowledge.
- **Productivity Tools**: Pomodoro timer for focused sessions and a GPA tracker to monitor progress.

### 👗 Style Mode
Look your best on campus without the daily stress:
- **Weather-Based Outfits**: Suggests clothing based on real-time weather data.
- **Campus Trends**: Curated fashion looks suitable for university environments.
- **Color Matching**: Helps you coordinate your wardrobe effortlessly.

### 🧘 Life Mode
Balance your personal well-being and daily responsibilities:
- **Smart Planner**: Reminders and habit tracking to stay on top of your schedule.
- **Health Tracking**: Monitor water intake, sleep patterns, and daily mood.
- **Finance Manager**: Keep track of campus expenses and budgets.

---

## 🛠 Tech Stack & Architecture

- **Language**: Java
- **UI Framework**: XML with ViewBinding for type-safe view access.
- **Navigation**: Android Jetpack Navigation Component for a seamless UX.
- **Backend (Scaffold)**:
    - **Firebase**: Authentication and Firestore integration (currently using mocked implementations for rapid prototyping).
    - **OpenAI**: Stubbed API integration ready for intelligent assistant features.
- **Architecture**: Modular design following Android best practices for scalability.

## 🏁 Getting Started

### Prerequisites
- Android Studio Jellyfish (or newer)
- JDK 17 or higher
- Android SDK 34+

### Installation
1. **Clone the repository**:
   ```bash
   git clone https://github.com/MaukiHimself/Salie-ai.git
   ```
2. **Open in Android Studio**:
   Select the `SALIE-AI` root folder.
3. **Sync Gradle**:
   Wait for the project to download dependencies and synchronize.
4. **Run**:
   Select a physical device or emulator and click the 'Run' icon.
